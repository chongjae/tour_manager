# 여행 대시보드 (tour_manager)

Google 스프레드시트 하나로 **일정(캘린더) · 지출(시트) · 가고 싶은 곳(My Maps) · 동선**을 한 화면에서 보고 입력하는 여행 대시보드입니다.
데이터는 전부 내 Google 계정(캘린더·시트·My Maps)에 남고, 대시보드는 그것을 보여주고 입력받는 창입니다. 서버·요금 없이 Google Apps Script로 동작합니다.

## 할 수 있는 것

- **동선**: 지도에서 장소를 순서대로 고르면 구간별 이동시간(자동차·대중교통·도보, 출발 시각 기준), 도착·출발 시각, 영업시간 기준 머물 수 있는 시간, 휴무·마감·브레이크타임 경고를 계산합니다. **짧은 동선으로 정렬** 버튼 하나로 순서를 다시 잡습니다.
- **캘린더 연동**: 항공편·숙박·예약 일정을 읽어 그날 출발지·출발 시각·마감(체크인, 출국편, 예약 시각)을 자동으로 반영하고, 짠 동선을 버튼 하나로 캘린더에 등록합니다.
- **지출**: 휴대폰에서 바로 입력 → 시트에 한 줄씩 기록. 카테고리·날짜별 합계, 환산 금액, **결제자별 정산(누가 누구에게 얼마)**. 센트 단위 통화, 여행 전 사전 결제(항공·숙소)를 원화로 입력, 기록 수정, **오프라인일 때 저장해 두었다가 연결되면 자동 전송**.
- **장소**: My Maps에 추가한 장소를 자동으로 읽고, 영업시간이 없는 곳은 (선택) Places API로 채웁니다.
- **같이 쓰기**: 동행자는 링크만 열면 같은 동선·지출을 봅니다. 여러 명이 다른 날을 동시에 고쳐도 서로 덮어쓰지 않고, 몇 분마다 서로의 변경이 반영됩니다. **보기 전용 링크와 편집 링크**를 나눌 수 있습니다.

## 이렇게 씁니다

> 아래 화면은 실제 대시보드 화면 코드를 **샘플 데이터(공개 관광지)와 모의 서버**로 로컬에서 띄워 찍은 것입니다 (이동시간도 모의 값). 다시 만들기: `python3 apps-script/build.py && python3 docs/capture.py`

### ① 여행 전 — 하루 동선 짜기 (PC)
가고 싶은 곳을 누르면 동선에 붙고, 도착·출발 시각과 **머물 수 있는 시간**이 바로 계산됩니다. 월요일 휴무인 소바집은 빨간 경고로 표시됩니다. **📏 짧은 동선으로 정렬**로 순서를 정리하고 **📅 캘린더에 등록**하면 일정이 Google 캘린더에 들어갑니다.

![동선 짜기](docs/images/route-planning.gif)

### ② 캘린더와 한눈에 — 일정 탭
항공편·숙박·예약(캘린더)과 대시보드에서 등록한 동선(📍)이 날짜별로 함께 보입니다. 위치가 없는 예약에는 장소를 직접 연결할 수 있습니다.

![일정 탭](docs/images/calendar-plan.png)

## 시작하기 (약 15분)

### 1. 템플릿 복사
[**템플릿 사본 만들기**](https://docs.google.com/spreadsheets/d/1UVaSC4_n43ytgG9kd6hCqRYebl33m6bG4gprz6izeYI/copy) → 내 Drive에 스프레드시트가 생깁니다. 스프레드시트에 연결된 코드도 함께 복사되지만, 웹 앱 배포는 복사되지 않아 4단계에서 직접 배포합니다.

### 2. 설정 탭 채우기
`설정` 탭의 노란 **값** 칸을 채웁니다. `[필수]`가 비어 있으면 대시보드는 설정 안내만 보여줍니다.

| 항목 | 필수 | 예시 | 설명 |
|---|---|---|---|
| 여행 제목 | ✅ | 오키나와 여행 | 화면 상단 제목 |
| 시작일 / 종료일 | ✅ | 2027-04-10 / 2027-04-14 | `YYYY-MM-DD`, 최대 31일 |
| 현지 시간대 | ✅ | Asia/Tokyo | [IANA 시간대](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones) (Asia/Bangkok, Europe/Paris …). 여행 중 서머타임이 바뀌면 바뀐 뒤 날짜의 시각이 1시간 어긋납니다 (시작일 기준 시차 하나만 사용) |
| 목적지 키워드 | ✅ | 오키나와, 나하, OKA | 항공편 제목의 `→` 오른쪽에 있으면 **도착편**, 왼쪽이면 **출국편** |
| My Maps 링크 | ✅ | `https://www.google.com/maps/d/edit?mid=…` | 3단계에서 만든 지도 |
| 현지 통화 이름 / 기호 | ✅ | 엔 / ¥ | 지출 입력 단위 |
| 환산 통화 기호 / 환율 | ✅ | ₩ / 9.3 | 현지 통화 1 = 환산 통화 얼마 |
| 결제자 / 결제수단 | ✅ | 나, 동행 / 카드, 현금 | 쉼표로 구분 |
| 지출 시트 이름 | ✅ | 여행_지출 | 없으면 자동 생성 |
| 부제 | | 렌터카 | 제목 옆 메모 |
| 입국 소요(분) | | 60 | 착륙 후 출발까지 |
| 출국편 공항 도착(분 전) | | 90 | |
| 기본 출발 시각 | | 09:00 | 숙소에서 출발하는 날 |
| 이동수단 | | 자동차 | 자동차 / 대중교통 / 도보 |
| 현지 통화 소수 자릿수 | | 0 | 유로·달러처럼 센트가 있으면 `2` |
| 환산 통화 소수 자릿수 | | 0 | 원화는 `0`, 달러는 `2` |
| 캘린더 ID | | (비움) | 비우면 기본 캘린더. 메뉴 **여행 대시보드 → 여행 전용 캘린더 만들기**를 누르면 자동으로 채워집니다 (권장) |
| 지도 타일 주소 | | (비움) | 비우면 OpenStreetMap. [지도 타일](#지도-타일) 참고 |

> **환율 자동**: `환율` 칸에 `=GOOGLEFINANCE("CURRENCY:JPYKRW")`처럼 수식을 넣으면 그날 환율을 씁니다 (통화 코드는 [ISO 4217](https://ko.wikipedia.org/wiki/ISO_4217)). 각 지출의 환산 금액은 입력한 순간의 환율로 고정됩니다.
> 예전 템플릿에서 수식이 글자로 보이면 그 칸의 **서식 → 숫자 → 자동**으로 바꾸세요.

> `설정` 탭이 없으면 스프레드시트 메뉴 **여행 대시보드 → 설정·안내 탭 만들기**.

### 3. My Maps 지도 만들기
1. [mymaps.google.com](https://www.google.com/maps/d/) → **새 지도 만들기**
2. 검색창에서 장소 검색 → **+ 지도에 추가** (공항·숙소도 추가해 두면 출발지로 쓰입니다)
3. **공유 → 링크가 있는 모든 사용자: 보기** (대시보드가 지도를 읽으려면 필요)
4. 지도 주소를 `설정 › My Maps 링크`에 붙여넣기

분류(식당·관광·쇼핑·숙소·교통)는 Places API가 켜져 있으면 자동, 아니면 My Maps **레이어 이름**을 `식당`/`관광`/`쇼핑`/`숙소`/`교통`으로 지으면 그 분류가 됩니다. 새 장소는 최대 10분 뒤 대시보드에 나타납니다.

### 4. 웹 앱으로 배포
1. 스프레드시트 메뉴 **확장 프로그램 → Apps Script**
2. 오른쪽 위 **배포 → 새 배포** → ⚙ 유형 **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **Google 계정이 있는 모든 사용자**
3. **배포** → 권한 검토 → 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**
   (직접 만든 스크립트라서 뜨는 경고입니다. 요청 권한: 캘린더, 이 스프레드시트, 외부 서비스 연결(My Maps·Places·버전 확인), 스프레드시트 메뉴 표시, 이메일 주소 보기(여행 전용 캘린더 메뉴에서 소유자 확인용))
   v1에서 업데이트하면 권한이 늘어나서 **다시 승인 화면**이 나옵니다.
4. 나오는 **웹 앱 URL**이 대시보드 주소입니다. 휴대폰에서 열고 *홈 화면에 추가*하면 앱처럼 쓸 수 있습니다.

> ⚠️ **링크를 아는 Google 로그인 사용자는 누구나 대시보드를 볼 수 있습니다** (로그인 안 한 사람은 열 수 없습니다). 링크는 동행자에게만 공유하세요.
> 이때 보이는 것: **여행 기간에 여행 캘린더(`캘린더 ID`, 비우면 기본 캘린더)에 있는 일정 전체(제목·위치)**, 지출 내역, 동선. 개인 일정이 섞이지 않도록 **여행 전용 캘린더**를 쓰세요.
>
> **보기·편집 링크 나누기 (권장)**: 스프레드시트 메뉴 **여행 대시보드 → 보기·편집 링크 보기**를 누르면 두 링크가 나옵니다. 보기 링크로는 아무것도 바꿀 수 없고, 편집 링크(`…/exec?k=…`)로만 지출 입력·동선 수정·캘린더 등록을 할 수 있습니다. 편집 링크가 새어 나갔으면 **편집 키 새로 만들기**로 예전 편집 링크를 무효로 만드세요.
> 편집 키를 만들지 않으면 지금처럼 링크를 가진 누구나 편집할 수 있습니다. 이때 할 수 있는 것: 지출 추가·수정·삭제, 동선 저장, 대시보드가 만든 동선 일정(`#trip-route`) 등록·교체. 직접 만든 캘린더 일정은 지우지 않습니다.
> 코드를 고친 뒤에는 **배포 관리 → 편집 → 새 버전**으로 같은 URL을 유지하세요 (새 배포를 만들면 URL이 바뀝니다).

### 5. 캘린더 일정 넣기 (여행 캘린더)
| 일정 | 이렇게 넣으면 | 대시보드 동작 |
|---|---|---|
| 도착 항공편 | 제목 `TG659 인천 → 방콕(BKK)`, 시간 = 비행 시간 | 그날 **공항에서 도착+입국 시간 후 출발** |
| 출국 항공편 | 제목 `TG658 방콕(BKK) → 인천` | 그날 마지막 목적지, 출발 N분 전 공항 도착 기한 |
| 숙박 | **체크인~체크아웃을 하나의 여러 날 일정**, 위치에 숙소 주소 | 첫날 마지막 목적지, 중간 날 출발지, 마지막 날 체크아웃 시각에 출발 |
| 예약 등 | 시간 + 위치 | 동선에 **고정 경유지**, 늦으면 경고 |
| Gmail이 만든 일정 | `Flight to Naha (NH 123)`, `Stay at …` (종일 여러 날) | 항공편·숙박으로 인식 (목적지 키워드에 **영문 지명**도 넣으세요). 종일 숙박은 첫날 체크인 15:00 / **마지막 날** 체크아웃 11:00으로 봅니다 (Gmail처럼 체크아웃 날짜까지 칠한 일정) |

> Gmail 자동 일정의 제목 형식은 언어·항공사에 따라 다를 수 있습니다. 인식되지 않으면 제목을 `KE741 인천 → 나하`처럼 바꾸세요.

일정 탭에서 위치가 없는 일정에 장소를 직접 연결할 수도 있습니다. 대시보드에서 등록한 동선은 `#trip-route` 표시가 붙은 일정으로 생기며, 다시 등록하면 그날 것만 교체됩니다.

### 6. (선택) 영업시간 자동 조회 — Places API
My Maps에서 검색해 추가한 장소의 영업시간·분류를 자동으로 채웁니다. 없으면 "영업시간 미상"으로 표시될 뿐 나머지는 동작합니다.
1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트 생성 → 결제 계정 연결 → **Places API (New)** 사용 설정
2. **사용자 인증 정보 → API 키** 생성 → 키 제한: *Places API (New)* 만
3. **할당량**에서 하루 요청 수를 100 정도로 제한 (요금 방지 장치)
4. Apps Script 편집기 → ⚙ **프로젝트 설정 → 스크립트 속성 → `PLACES_API_KEY`** 에 키 저장 (시트·채팅에 키를 붙이지 마세요)

한 번 조회에 성공한 장소는 숨김 탭 `_영업시간`에 저장되어 다시 호출하지 않고(API 오류가 난 곳은 다음에 다시 시도), 한 번 열 때 최대 10곳만 조회합니다. 이동시간 조회(무료 내장 기능)는 하루 500건으로 제한되고, My Maps 장소 주변(약 50km)의 구간만 조회합니다 (그 밖은 직선거리 추정). 일반적인 여행 규모(장소 수십 곳)라면 월 무료 사용량 안에 들어갑니다.

## 지도 타일

지도 배경은 기본으로 OpenStreetMap 공식 타일(`tile.openstreetmap.org`)을 씁니다. OSM [타일 이용 정책](https://operations.osmfoundation.org/policies/tiles/)은 **배포된 앱의 대량 사용을 금지**하고 타일 주소를 바꿀 수 있게 하라고 권합니다. 몇 명이 여행 기간에 쓰는 정도는 문제가 되지 않지만, 많이 쓰거나 차단되면 `설정 › 지도 타일 주소`를 다른 제공자로 바꾸세요.

- 예: [CARTO](https://carto.com/basemaps) (무료 API 키 필요, 월 500만 타일) → `https://{s}.basemaps.cartocdn.com/rastertiles/voyager/{z}/{x}/{y}.png?api_key=발급받은키`
- 주소는 `https://`로 시작하고 `{z}` `{x}` `{y}`가 들어 있어야 합니다. 제공자의 이용 약관과 표기 규칙을 확인하세요.
- 타일 주소에 넣은 API 키는 **대시보드를 여는 모든 사람의 브라우저에 보입니다.** 제공자 콘솔에서 키를 사용 도메인(`*.googleusercontent.com`)으로 제한하세요.

## 업데이트

새 버전이 나오면 대시보드 상단 띠에 **새 버전 있음 → 업데이트 방법**이 나타납니다 (GitHub의 [`VERSION`](VERSION)을 하루 몇 번 확인).

- **개발자 (clasp)**: `git pull && python3 apps-script/build.py && (cd apps-script && npx @google/clasp push -f)` → **배포 관리 → 편집 → 새 버전** (URL 유지).
  코드를 올린 뒤 스프레드시트를 다시 열면 `설정` 탭에 **새 버전의 설정 항목이 자동으로 추가**되고 (기존 값은 그대로) `안내` 탭이 새 내용으로 바뀝니다.
- **그 밖의 사용자**: 최신 [템플릿 사본](#1-템플릿-복사)을 새로 만들고, `설정` 탭 값을 옮겨 붙인 뒤, 기존 지출 탭은 **탭 우클릭 → 복사 → 기존 스프레드시트**로 새 사본에 옮깁니다. 웹 앱을 새로 배포하면 **URL이 바뀌므로** 동행자에게 새 링크를 보내세요.
  이 방식으로는 대시보드에만 저장된 **동선·장소 연결·출발 시각은 옮겨지지 않습니다** (캘린더에 등록한 동선 일정은 남습니다).

## 문제 해결

| 증상 | 해결 |
|---|---|
| "현재 파일을 열 수 없습니다" | 브라우저에 Google 계정이 여러 개 로그인된 경우의 Apps Script 알려진 문제. **시크릿 창에 계정 하나만** 로그인하거나 휴대폰에서 여세요 |
| 노란 띠 "설정이 필요합니다" | `설정` 탭의 [필수] 칸 / 형식 오류 목록대로 수정 후 새로고침 |
| "My Maps를 읽지 못했습니다 (HTTP 403)" | 지도 공유를 **링크가 있는 모든 사용자 보기**로 |
| "공항이 없어 항공편 일정을 출발지로 쓰지 못합니다" | My Maps에 공항을 추가 |
| 이동시간 앞에 `~ (직선거리 추정)` | 경로 조회 중이거나 실패. 잠시 후 새로고침. 계속되면 Apps Script ⏱ 실행 기록 확인 |
| "Places API 오류 403" | 키 제한 / API 사용 설정(Places API **(New)**) 확인 |
| 새 장소가 안 보임 | My Maps 반영은 최대 10분 |
| 무엇이 문제인지 모르겠음 | 일정 탭 맨 아래 **⚙ 설정 점검** (설정·My Maps 공유·캘린더·Places 키·편집 키 상태). 설정이 덜 끝났으면 첫 화면에 자동으로 표시 |
| 상단에 "보기 전용 링크" | 편집 키가 켜져 있습니다. 편집 링크(`?k=…`)로 여세요 |
| "⏳ 전송 대기" 지출 | 오프라인이었던 기록입니다. 연결되면 자동 전송되고, 같은 기록이 두 번 들어가지 않습니다 |
| 지출 날짜 "여행 전" | 항공권·숙소 같은 사전 결제. 금액 위 **환산 통화로 입력**을 누르면 원화 그대로 넣을 수 있습니다 |

## 개발자

```
apps-script/   서버 (Apps Script): Code · Config(설정 탭) · Admin(메뉴·편집 키) · Expenses · Calendar · Maps · Places
prototype/     화면 (원본 JS) + 단위 테스트 + 로컬 E2E. 서버 없이도 샘플 데이터로 동작
```

- 화면 원본은 `prototype/*.js`. `python3 apps-script/build.py`가 이를 Apps Script용 `index.html` + `js_*.html`로 묶습니다.
- **주의**: Apps Script는 페이지를 내보낼 때 `//` 주석을 지우면서 **템플릿 리터럴(백틱) 안의 `//`까지 잘라냅니다.** URL은 일반 문자열 상수로 두세요 (`build.py`가 검사해서 막습니다).
- 배포 (clasp):
  ```bash
  cp apps-script/.clasp.json.example apps-script/.clasp.json   # scriptId / parentId 입력
  npx @google/clasp login
  python3 apps-script/build.py && (cd apps-script && npx @google/clasp push -f)
  ```
- 테스트:
  ```bash
  node --test prototype/*.test.js apps-script/server.test.mjs  # 단위 (경로·일정·영업시간·정산, 서버 입력 검증·권한·병합)
  python3 -m http.server 8600 -d prototype &                     # 로컬 샘플 화면
  python3 prototype/e2e.py http://127.0.0.1:8600/                # 화면 E2E (playwright)
  python3 apps-script/build.py && python3 apps-script/e2e_gas.py # 서버 응답을 흉내 낸 Apps Script 모드 E2E (방콕 설정 포함)
  python3 apps-script/kml_check.py <내지도.kml>                   # 실제 My Maps KML 파싱 확인
  ```
- 템플릿 시트 재생성: `python3 apps-script/make_template.py` (설정 항목·안내 문구는 `Config.js`에서 읽음)
- 쓰기 서버 함수는 **마지막 인자로 편집 키**를 받습니다 (`requireEdit_`). 화면은 `callWrite()`로만 호출합니다. 새 서버 함수는 `e2e_gas.py`의 가짜 서버에도 추가하세요 (빠지면 E2E가 실패합니다).
- 릴리스: `VERSION`과 `Code.js`의 `VERSION`을 함께 올립니다 (단위 테스트가 확인). 설계·검증 기준: [`docs/PUBLIC_RELEASE.md`](docs/PUBLIC_RELEASE.md)
